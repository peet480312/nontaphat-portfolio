## ✨ Features

- **Responsive Design** - Works on desktop, tablet, and mobile
- **Dark Theme** - Modern dark color scheme
- **Smooth Scroll** - Smooth navigation between sections
- **Mobile Menu** - Hamburger menu for mobile devices
- **Active Menu Highlight** - Shows current section in navbar
- **Back to Top Button** - Quick navigation to top

- **Project Showcase** - Display projects with status badges
- **Skills Overview** - Organized skill categories
- **Learning Journey** - Checklist of progress

## 🚀 Getting Started

### Local Development

1. Clone or download this repository
2. Open `index.html` in your browser
3. No build tools or dependencies required

### Quick Start

```bash
# Clone the repository
git clone https://github.com/yourusername/portfolio.git

# Navigate to project folder
cd portfolio

# Open in browser (macOS)
open index.html

# Or use VS Code Live Server extension
```
